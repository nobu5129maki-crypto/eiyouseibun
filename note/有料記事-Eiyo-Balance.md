## 【無料公開ここまで】リード（有料線の手前に置く文）

「今日、食べすぎたかな」——そう思ってカロリーアプリを開いても、結局つづかない人は多いです。

理由はだいたい次のどちらかです。

1. **食事写真を撮るのが面倒**（外食・コンビニ・家族の食事で毎回カメラを向ける気にならない）  
2. **数字の根拠がふわっとしている**（海外基準のまま／なんとなくの目標値）

そこで作ったのが、ブラウザだけで動く栄養バランス管理アプリ **Eiyo Balance** です。

- 食事そのものの写真は使わない  
- 代わりに **パッケージの「栄養成分表示」を読む**  
- 食べた内容は **日本語で書いて概算**  
- 1日の目安は **厚生労働省「日本人の食事摂取基準（2025年版）」** を軸に算出  

無料部分では「どんなアプリか」だけをお伝えします。  
有料パートでは、**実際の使い方・画面の読み方・続くコツ・向かない人・設計の裏側**まで、このアプリを使い倒すための内容をまとめています。

## 【ここから有料】

# 第1章　なぜ「食事写真アプリ」を捨てたのか

世の中の栄養アプリの多くは、皿の写真からAIでカロリーを推定します。便利に見えますが、現場では次の弱点があります。

- 盛り付け・ソース・油で誤差が跳ねやすい  
- 「それっぽい数字」が出てしまい、確認が雑になりやすい  
- プライバシー的にも、食事写真をクラウドに送る設計が多い  

Eiyo Balanceは逆の方針を取りました。

| やること | やらないこと |
|---|---|
| 栄養成分表示のカメラ読取 | 食事プレート写真での推定 |
| 日本語の食事テキストから概算 | アカウント必須のクラウド同期 |
| 保存前の数値確認・手修正 | インストール必須のネイティブアプリ |

つまり **"測る"より"確認する"** を前面に出したアプリです。  
コンビニのおにぎり、プロテインバー、飲料——パッケージに数字が書いてあるものは、その数字を取りにいく。  
家庭料理や外食名は、日本語の食品辞書で概算し、最後は自分の目で直す。

この一手間が、逆に「信用できる記録」につながります。

# 第2章　Eiyo Balanceの全体像（5画面）

アプリはタブ構成です。覚えるのはこれだけ。

1. **ホーム** … 今日の進捗と警告  
2. **記録**（ホームのボタンから）… ラベル読取 / テキスト推測 / 手入力  
3. **履歴** … 日・週・月のグラフ  
4. **提案** … 足りない栄養のヒント  
5. **設定** … プロフィール・目安根拠・個別削除  

インストールは不要です。スマホのブラウザで開けば使えます（カメラ読取はHTTPS環境が必要）。

# 第3章　最初の5分セットアップ

## 3-1. プロフィールを入れる

初回はオンボーディングに入ります。

入力するものは次のとおりです。

- 表示名  
- 年齢・性別  
- 身長・体重  
- 活動量（ほとんど動かない〜非常に活発）  
- 目標（減量 / 維持 / 増量）  

「目安を計算」を押すと、1日の摂取目安がプレビューされます。問題なければ保存。

## 3-2. 目安の考え方（ここが有料読者向けの核心）

エネルギーは、体格から基礎代謝を推定し、活動量と目標（減量なら控え目／増量なら上乗せ）を反映した簡易目安です。  
たんぱく質・脂質・炭水化物は、そのエネルギーを土台に配分します。

一方で、次の項目は **厚生労働省「日本人の食事摂取基準（2025年版）」** の推奨量・目標量を性別・年齢で簡易反映しています。

- 食塩  
- 食物繊維  
- ビタミンC  
- カルシウム  
- 鉄  

設定画面の「目安の根拠」から、厚労省の公式ページへも飛べます。  
医療上の指示がある方は、必ずそちらの指示を優先してください（アプリは簡易目安です）。

# 第4章　記録の三種の神器

記録画面には3つの入り口があります。使い分けが上達のコツです。

## 4-1. 栄養成分表示の読取（いちばん正確）

向いているもの:

- コンビニ食品  
- 飲料・プロテイン  
- 加工食品のパッケージ  

手順:

1. ホームで「ラベル読取」  
2. カメラで成分表を撮る、または画像を選ぶ  
3. 読み取り結果（エネルギー・たんぱく質など）を確認  
4. おかしい数字は手で直して保存  

ポイントは **「読めたら終わり」にしない** こと。OCRは便利ですが誤読もあります。信頼度が低いときは画面でも注意が出ます。必ず保存前に見直してください。

## 4-2. テキスト推測（いちばん速い）

向いているもの:

- 「かつ丼」「ビッグマック」「牛乳200ml」など日常の言い方  
- 家庭料理・外食・チェーンメニュー名  

例:

- `かつ丼`  
- `ビッグマック`  
- `チーズバーガー`  
- `ブロッコリー100g`  
- `ハイボール`  

辞書に載っている食品は、日本の食品成分表や外食・製品栄養の概算を使って数値化します。  
飲料は ml、食材は g で分量調整できるものもあります。

重要な仕様:

- **辞書にない食品は、勝手に“普通の1食”を当てません**  
- 未登録なら手入力へ回す設計です  

だから「反応しない」ときは、名前を変えるか手入力してください。辞書は丼物・アルコール・ファストフードなども順次広げています。

## 4-3. 手入力（いちばん自由）

成分表が読みづらいとき、外食でざっくり入れたいとき用です。  
名前と数値を自分で入れて保存します。精度の最終防衛ラインです。

# 第5章　ホーム画面の読み方（続けられる人の見方）

ホームは「達成度ゲージ」ではありません。**過剰を見つけるダッシュボード**です。

見る順番のおすすめ:

1. **エネルギー・PFC・食塩**が目安を超えていないか  
2. **食物繊維・ビタミンC・カルシウム・鉄**が極端に薄くないか  
3. 今日の食事一覧で、朝昼晩の偏りを確認  

超過が出たら、その日は「足す」より「置き換える・減らす」を優先すると続きやすいです。  
不足のヒントは「提案」タブにもまとまっています。

---

# 第6章　履歴で“週の癖”を見る

履歴は **日別 / 週別 / 月別** に切り替えられます。

おすすめの使い方:

- **日別**: 昨日食べすぎた理由を思い出す  
- **週別**: 週末だけ食塩や脂質が跳ねる、などの生活リズムを見つける  
- **月別**: 目標（減量/維持）との中長期のズレを見る  

グラフには目安線が出るので、「合計が多いか」だけでなく「目安に対してどうか」が直感的にわかります。  
不要な記録は履歴・設定のどちらからでも個別削除できます。

# 第7章　実戦シナリオ（そのまま真似できる）

## シナリオA：コンビニ昼ごはん

1. おにぎり＋サラダチキンの成分表をラベル読取  
2. 飲み物が成分表なしなら「お茶」などをテキスト or 手入力  
3. ホームで食塩とたんぱく質を確認  

## シナリオB：ファストフード

1. `ビッグマック` や `モスバーガー` をテキスト入力  
2. ポテトも別記録（`マックフライポテト` など）  
3. 1日の残り枠を見て夜を調整  

## シナリオC：居酒屋・アルコール

アルコールはエネルギーが「炭水化物ゼロ」でも乗ることがあります。  
ハイボールや日本酒などもテキスト対応していますが、**あくまで概算**。気になるときは手修正を。

## シナリオD：減量中の夜

ホームでエネルギーが80〜100%に近づいていたら、夜は「丼＋揚げ物」より「たんぱく質＋野菜」側へ寄せる。  
提案タブで不足している微量栄養素をチェックすると、削りすぎ防止にもなります。

# 第8章　設定まわりで知っておくこと

- プロフィールを変えたら目安は再計算されます  
- 食事記録は一件ずつ削除可能（全部消す必要はない）  
- 「すべてのデータを削除」はプロフィール込みで消えるので注意  

データの置き場は、お使いのブラウザ内です。  
ログイン同期はないため、**ブラウザのデータ消去や機種変更で消える**点は理解したうえで使ってください。  
その代わり、アカウント登録なし・サーバに食事内容を預けない、という軽さがあります。

# 第9章　向いている人 / 向かない人

## 向いている人

- コンビニ・加工食品が多く、成分表を見る習慣をつけたい  
- 「写真AIの数字」より、確認できる数字が欲しい  
- 日本の食事摂取基準ベースで目安を置きたい  
- インストールなしで今すぐ試したい  

## 向かない人（正直に書きます）

- 皿写真だけで全部自動記録したい人  
- 未登録料理でも必ずそれらしい数字を出してほしい人  
- 家族分をクラウドで共有・バックアップしたい人  
- 疾患の食事療法をアプリ任せにしたい人（医療代替にはなりません）  

有料記事でここを隠すとクレームになります。だから先に書きます。

# 第10章　精度を上げる運用ルール（筆者推奨）

1. **加工食品はラベル読取を優先**  
2. **テキスト推測のあとは必ず数値を一目確認**  
3. **辞書にないものは無理に当てず手入力**  
4. **食塩はエネルギーより先に見る日をつくる**（日本人の食事で詰まりやすい）  
5. **週1回だけ履歴の週別を見る**（毎日完璧を目指さない）  

栄養管理は、正確な記録より **続く記録** が強いです。  
Eiyo Balanceは「完璧な推定」より「確認しやすい導線」に寄せています。

---

# 第11章　このアプリの設計思想（作り手視点）

技術的には Vite + React のWebアプリで、OCRは端末側（ブラウザ）で動かす構成です。  
食事写真推定を捨てたのは、実装を楽にするためではなく、**ユーザーが数字を信じすぎない設計**にするためです。

また、1日目安は「日本人の食事摂取基準（2025年版）」を参照し、基準が改定されたらアプリ側も追従する運用にしています。  
流行りの海外テンプレ目標をそのまま貼らない——これが日本向けアプリとしての最低条件だと考えています。

# 終章　今日からの一歩

やることは3つだけです。

1. https://eiyouseibun.vercel.app を開く  
2. プロフィールを入れて目安を出す  
3. 今日の食事を「ラベル読取」か「テキスト」で1件入れる  

最初の1件が、いちばん重いです。  
そこを越えると、「測るアプリ」ではなく「確認する習慣」に変わります。

この記事が、あなたの食事ログを“なんとなく”から“確認できる記録”に変えるきっかけになれば幸いです。
